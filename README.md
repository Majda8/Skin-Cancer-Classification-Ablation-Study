# Skin Cancer Classification - Ablation Study

This project focuses on an ablation study to compare different architectures for the classification of skin diseases using the [Skin Cancer MNIST: HAM10000 dataset](https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000) from Kaggle. The goal is to explore and evaluate multiple deep learning models and architectures to identify the best-performing model for skin cancer classification.

## Dataset

The dataset used in this project is the **HAM10000** dataset, which contains images of skin lesions labeled with different skin cancer types. The dataset includes over 10,000 dermoscopic images, which are classified into multiple classes of skin diseases, such as malignant melanoma, basal cell carcinoma, and more.

You can access the dataset here:  
[Kaggle - Skin Cancer MNIST: HAM10000](https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000)
